**Telco Customer Churn Analysis and Predictive Insights**

**Project Overview**

This project focuses on analyzing customer churn behavior in a telecom company using data analytics and visualization techniques. The goal was to identify the major factors contributing to customer churn and generate actionable business insights that can help improve customer retention strategies.
The project involved cleaning and analyzing more than 7,000 customer records using Python, SQL, Excel, and Power BI.

**Features**
Data cleaning and preprocessing
Exploratory Data Analysis (EDA)
Churn trend analysis
Customer segmentation
KPI dashboard creation
Business insight generation
Data visualization using Power BI

**Technologies Used**
Python
SQL
Excel
Power BI
Pandas
NumPy
Matplotlib
Seaborn

**Key Insights**
Customers with month-to-month contracts showed higher churn rates.
Higher monthly charges were strongly associated with churn.
Customers with shorter tenure were more likely to leave the service.
Long-term contract users had better retention rates.
